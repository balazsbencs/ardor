# Rev C local footprints

These geometry snapshots are inherited from the reviewed compact Rev 2 board. Rev C retains their pad geometry for all populated components; op-amp and passive substitutions use the same packages. The local Panasonic FK D6.3/H5.8 footprint remains manufacturer-specific. The `fp-lib-table` uses project-relative paths. Unused full-revision footprints are retained as library snapshots, not placed components.
