# 1073 EQ

An original MIT-licensed three-band console EQ, available under **Utility →
1073 EQ** on the pedal and in Manager. Its preset identifier is
`eq / console_1073`.

The control frequencies and ranges follow the published
[AMS Neve 1073 specifications](https://www.ams-neve.com/outboard/1073-range/1073-mic-preamp-equaliser/).
The DSP uses standard digital filter designs and an original saturation stage.
It does not port EQ1979 code, tuning tables, noise generation, artwork, or its
saturation model. It is a 1073-style musical EQ, not a measured hardware or
transformer/circuit emulation.

| Control | Range / positions |
| --- | --- |
| Low gain | ±16 dB |
| Low frequency | Off, 35, 60, 110, 220 Hz |
| Mid gain | ±18 dB |
| Mid frequency | Off, 360, 700 Hz, 1.6, 3.2, 4.8, 7.2 kHz |
| High gain | ±16 dB, fixed 12 kHz shelf |
| High-pass | Off, 50, 80, 160, 300 Hz; 18 dB/octave |
| Saturation | 0–100%, default Off |
| Output trim | ±24 dB |
| Polarity | Normal / Inverted |
| Mix | 0–100%, default 100% |

Adding the block gives zero band gains, low frequency 60 Hz, mid frequency
1.6 kHz, HPF off, saturation off, unity output trim, and normal polarity. The
block does not add noise. Low and mid Off positions disable their respective
bands, including any stored gain. The usual block enable switch bypasses the
whole processor.

## Processing

The input runs through a symmetric `tanh` saturation at twice the host sample
rate, then the high-pass, low shelf, fixed-Q mid bell, and high shelf. Saturation
has unity gain for very small inputs and compresses larger inputs progressively;
output trim adjusts the level after the EQ. Saturation at zero is linear. The
shared halfband filters still run when saturation is off, so latency is constant
and there is a gentle roll-off near Nyquist.

The low/high shelves use cookbook biquads with Q = 1/√2; the mid bell has
Q = 0.7. The HPF combines a first-order section and a Q = 1 second-order section
for a third-order Butterworth response. Gain targets use 10 Hz smoothing and
coefficients update every 32 samples while the gains move. Frequency switches
crossfade two independent filter banks over 10 ms; rapid changes retain the
latest requested position until the current fade completes. Output, saturation,
Mix and polarity also slew rather than jumping. Polarity applies to the wet
path, before Mix.

The processor has **15 host samples of latency** (0.3125 ms at 48 kHz).
Mix uses a matching dry delay and RuntimeChain maintains that delay during
bypass. Left/right histories are independent. Audio processing uses fixed-size
storage and atomic parameter targets, with no allocation or locks on the audio
thread. The processor accepts 32–192 kHz; Ardor normally runs at 48 kHz.

All ten controls support live edits and scenes, including console EQs inside
Dual Rig lanes and WDW dry lanes. Switches use stepped scene transitions;
gains use dB transitions. Presets store gain/trim in dB, saturation/Mix in 0–1,
and switches as integer positions starting at zero. For example:

```json
{
  "id": "console-eq",
  "type": "eq",
  "enabled": true,
  "asset": "",
  "params": {
    "mode": "console_1073",
    "low_db": 2,
    "low_freq": 2,
    "mid_db": -3,
    "mid_freq": 3,
    "high_db": 2,
    "high_pass": 2,
    "saturation": 0.2,
    "output_db": -2,
    "polarity": 0,
    "mix": 1
  }
}
```

## Validation

`pedal-console-eq-smoke` checks default response at five sample rates,
boost/cut reciprocity, all low/mid frequency positions, all HPF cutoffs and
roll-off, band Off, stereo separation, saturation, polarity, dry Mix,
rapid automation, reset, invalid parameters, preset planning, engine and lane
loading, pedal controls, scenes, and bypass latency. Manager catalog and inspector
tests cover default values and labeled numeric switch edits.
