# 1073 EQ

An original MIT-licensed three-band console EQ, available under **Utility →
1073 EQ** on the pedal and in Manager. Its preset identifier is
`eq / console_1073`.

The control frequencies and ranges follow the published
[AMS Neve 1073 specifications](https://www.ams-neve.com/outboard/1073-range/1073-mic-preamp-equaliser/).
The DSP uses standard digital filter designs and an original saturation stage.
It does not port EQ1979 code, tuning tables, noise generation, artwork, or its
saturation model. It is a 1073-style musical EQ, not a measured hardware or
transformer/circuit emulation.

| Control | Range / positions |
| --- | --- |
| Low gain | ±16 dB |
| Low frequency | Off, 35, 60, 110, 220 Hz |
| Mid gain | ±18 dB |
| Mid frequency | Off, 360, 700 Hz, 1.6, 3.2, 4.8, 7.2 kHz |
| High gain | ±16 dB, fixed 12 kHz shelf |
| High-pass | Off, 50, 80, 160, 300 Hz; 18 dB/octave |
| Saturation | 0–100%, default Off |
| Character | Clean / Console, default Console |
| Output trim | ±24 dB |
| Polarity | Normal / Inverted |
| Mix | 0–100%, default 100% |

Adding the block gives zero band gains, low frequency 60 Hz, mid frequency
1.6 kHz, HPF off, saturation off, Character Console, unity output trim, and
normal polarity. The
block does not add noise. Low and mid Off positions disable their respective
bands, including any stored gain. The usual block enable switch bypasses the
whole processor.

## Processing

The input runs through a symmetric `tanh` saturation at twice the host sample
rate, then the high-pass, low shelf, fixed-Q mid bell, and high shelf.

Saturation sets a drive from 0 to 8 (the square of the control, times 8). A
makeup gain keeps the mean peak of a -12 dBFS sine at its own level, so more
saturation adds harmonics rather than reducing the level. At full saturation a
-12 dBFS signal is about 1.2 dB louder, and quieter signals gain up to about
6 dB, like a light compressor. Only the distortion residue, the curve minus the
linear signal, goes through first-order antiderivative anti-aliasing (ADAA).
The linear path is therefore exact. At full saturation with a -6 dBFS sine,
folded harmonics stay below -80 dBc for inputs up to 4 kHz and near -71 dBc at
6 kHz. Saturation below about 4% is exactly linear. The shared halfband filters
still run when saturation is off, so latency is constant and there is a gentle
roll-off near Nyquist.

## Character

**Console** (the default) adds four musical approximations of console
behavior. They are not measurements of a hardware unit.

- **Class-A bias.** The saturation curve is offset, so it adds even harmonics.
  At 50% saturation the 2nd harmonic of a -12 dBFS sine is about 6 dB above the
  3rd. A 5 Hz high-pass on the distortion residue removes the DC that the
  offset curve makes; the linear path is not filtered.
- **Output transformer.** After the EQ, a soft curve compresses the band below
  about 100 Hz, so bass saturates first and the highs stay clean. A low-shelf
  boost drives it harder.
- **Low-shelf bump.** The low shelf uses Q = 1 instead of 1/√2. A +12 dB boost at
  110 Hz then peaks about +0.8 dB above its plateau below the corner and dips
  about 0.8 dB above it.
- **Proportional mid.** The mid Q goes from 0.5 at small gains to 1.0 at
  ±18 dB, so small moves are broad and large ones are focused.

The bias and the transformer scale with saturation, and the curve shapes only
appear with gain. With zero gains and no saturation, Clean and Console give
bit-identical output. **Clean** keeps symmetric saturation and fixed Q
(1/√2 shelves, 0.7 mid). A Character change crossfades like a frequency switch,
and the saturation character follows it with 10 Hz smoothing.

The shelves and the mid bell are cookbook biquads (Q per Character, above). The HPF combines a first-order section and a Q = 1 second-order section
for a third-order Butterworth response. Gain targets use 10 Hz smoothing and
coefficients update every 32 samples while the gains move.

Frequency switches crossfade two filter banks. The new bank copies the history
of every section whose switch did not change, so a mid change does not restart
the HPF or the low shelf. Sections whose switch changed start from silence. The
fade takes 40 ms when the low or HPF switch changes, because those corners
settle slowly, and 10 ms for a mid change. Rapid changes retain the latest
requested position until the current fade completes. Output, Mix and polarity
also slew rather than jumping.

Output trim and polarity act on the final dry + wet sum. Polarity Inverted
therefore flips the whole block at any Mix setting and never cancels the dry
signal.

The processor has **15 host samples of latency** (0.3125 ms at 48 kHz).
Mix uses a matching dry delay and RuntimeChain maintains that delay during
bypass. Left/right histories are independent. While the chain is still mono,
RuntimeChain asks for one channel only; the processor copies the left history to
the right when stereo input arrives. Audio processing uses fixed-size storage
and atomic parameter targets, with no allocation or locks on the audio thread.
The processor accepts 32–192 kHz; Ardor normally runs at 48 kHz.

All eleven controls support live edits and scenes, including console EQs inside
Dual Rig lanes and WDW dry lanes. Switches use stepped scene transitions;
gains use dB transitions. Presets store gain/trim in dB, saturation/Mix in 0–1,
and switches as integer positions starting at zero. For example:

```json
{
  "id": "console-eq",
  "type": "eq",
  "enabled": true,
  "asset": "",
  "params": {
    "mode": "console_1073",
    "low_db": 2,
    "low_freq": 2,
    "mid_db": -3,
    "mid_freq": 3,
    "high_db": 2,
    "high_pass": 2,
    "saturation": 0.2,
    "character": 1,
    "output_db": -2,
    "polarity": 0,
    "mix": 1
  }
}
```

## Validation

`pedal-console-eq-smoke` checks the DSP: default response at five sample rates,
boost/cut reciprocity, all low/mid frequency positions, all HPF cutoffs and
roll-off, band Off, stereo separation, saturation level and harmonics, alias
products for both characters, the Character curves and harmonics, the
transformer stage, polarity at full and half Mix, dry Mix, switch fades against a settled
processor, the mono block path against the stereo path, rapid automation,
reset, and invalid parameters.

`pedal-console-eq-integration-smoke` checks preset planning, engine and lane
loading, live updates inside a Dual Rig lane and a WDW dry lane, pedal controls,
scenes (including Character), and bypass latency.
`pedal-manager-effect-catalog-smoke` checks that
the Manager catalog matches the pedal control table, including switch labels.
Manager catalog and inspector tests cover default values and labeled numeric
switch edits.
