Two-lane wet/dry/wet feasibility probe
Date: 2026-09-08
Target: Raspberry Pi at 192.168.88.12 (aarch64, service stopped during probe)

Topology measured
  Dry lane: Rat (exact run) -> NAM (JCM800) -> dense synthetic 8192-frame cab IR
  Wet lane: NAM (Ampeg/Dumble) -> dense synthetic 8192-frame cab IR -> stereo digital delay -> stereo room reverb
  Audio callback: CPU 1 for the matrix, CPU 2 for the placement check
  Dry worker: CPU 0, wet worker: CPU 3, SCHED_FIFO priority 69
  Publication: accept only equal dry/wet generations; otherwise hold the last
               complete pair, with initial silence (never raw-input bypass)
  All runs used paced 48 kHz input and a 2-slot bounded pipeline.

Final admission follow-up (2026-09-09)
  The probe was extended with --cab-path and a deterministic mono 48 kHz /
  8192-frame cabinet-shaped WAV fixture. The deployed image has no licensed
  cabinet capture, so this is a production-loader stress proxy; provenance is
  in benchmark-results/representative-cab-ir-48k.txt.

  128-frame / three-slot / Rat + cab / 1,000,000 paced timed blocks plus 200
  warmup blocks produced 1,000,196 matched pairs out of 1,000,200 calls,
  four bounded underflows, one maximum pair age block, zero submission misses,
  zero callback deadline misses, and zero non-finite/fault blocks. Measured
  latency was dry 0 frames and wet 31 frames. Callback mean / p99 / p999 / max
  were 18.938 / 26.426 / 45.481 / 114.296 us; worker maxima were 2,354.722
  us dry and 2,050.777 us wet against the 2,666.667 us quantum. Exact CSV:
  benchmark-results/wdw-feasibility-pi4-20260908-real-ir-1m.csv.

  All 25 dry/wet pairs from the five NAM models on the Pi were then screened at
  128 frames with the same fixture (100 warmup + 1,000 paced timed blocks per
  pair). Every pair stayed on dry CPU 0 / wet CPU 3, with one startup
  underflow, zero submission/deadline/non-finite/fault blocks, and 31 wet
  latency frames. Worst worker maxima were 1,788.156 us dry and 1,466.686 us
  wet. Exact CSV: benchmark-results/wdw-model-pair-screen-pi4-20260909.csv.

  The service was started after the probes; telemetry returned to over=0,
  gaps=0, worker_over=0, nonfinite=0, and block_mismatch=0.

Feasibility decision
  The topology is feasible as a bounded two-worker pipeline on this Pi when
  the complete lanes run off the callback and publication is generation matched.
  64 frames is a practical minimum for the Rat-enabled case; 128 frames gives
  more worker headroom. 32 frames had zero callback misses in this run but the
  dry worker's worst sample slightly exceeded one quantum, so it should not be
  the default admission point without stricter worst-case testing.
  The editor contract can therefore expose two complete lanes, each with its
  own NAM and cab, with delay/reverb restricted to the wet lane. The follow-up
  pair/program work now supplies the explicit latency/underflow policy and
  stopped-audio control-thread builder/activation seam; this historical probe
  itself does not change the live route.
