4. Poster

Built for the dark stage at 1.5 m. No boxes, no chrome: huge names, huge footswitch numerals, and one yellow flood for the live preset.

What changes

  • The four quadrants are the four footswitches. Thin rules separate them. There are no cards.
  • A 380 px ghost numeral sits behind each name, so the footswitch number reads even from the side.
  • The live quadrant floods yellow. Yellow is brighter than red on a dark stage and survives glare better.
  • The tuner fills the whole screen. When the note is in tune, the whole screen turns yellow, which you can see with peripheral vision.
  • Navigation becomes a text rail with an underline, not a row of grey boxes.

LVGL build notes

  • Ghost numerals: a digits-only font (1 to 4, about 380 px) keeps flash cost small. Compile it with lv_font_conv like the tuner font.
  • Tuner strip: 41 flat lv_obj cells. Recolour only the cells that change, which is cheap at 200 Hz.
  • Screen flood on in-tune: one bg_color change on the screen object. No tween, per spec section 11.
  • Text-only rail buttons still need a 60 px hit box with lv_obj_set_ext_click_area.
