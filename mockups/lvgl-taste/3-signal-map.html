3. Signal Map

The chain is the picture. Every preset tile draws its own signal path, and parameters become large arc knobs that the rotary encoder turns directly.

What changes

  • Each tile draws its chain as family-coloured nodes on a rail. On the live tile the rail and the nodes light up.
  • The header gets flat IN and OUT segment meters, so the screen shows that sound is passing. Amber marks a hot input.
  • Continuous parameters become 270 degree arcs with the value in the centre. The encoder turns the selected arc.
  • Choice parameters stay as segmented rows, but sit below the arcs as one group.

LVGL build notes

  • Arcs: lv_arc with flat indicator colour and arc_rounded 0. The scale ticks are an lv_scale in round mode.
  • Flow nodes: LV_RADIUS_CIRCLE objects on a 3 px rail. Label text comes from a short name per block type.
  • Meters need input and output peak values in RuntimeTelemetry. Check if the engine publishes them now.
  • Teal lamp is a new palette. It could ship as a fifth PaletteId next to Slate, Ink, Sodium and Nord.
