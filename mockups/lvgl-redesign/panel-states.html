Keys are plates, not rounded buttons. The keyboard inherits the panel vocabulary exactly — 1 px rules, flat fills, engraved caps — so it does not read as a borrowed OS component. Keys are 82 px wide and 44 px tall, above the touch floor. Enter takes the `engrave` fill because it commits; Shift, Del and 123 stay secondary in `engrave_lo`. The field being edited takes an `engrave` border and a caret, which is the only focus signal needed when one field is active at a time.

Full screen, not the 480 px drawer. The module drawer picks a block type from a short fixed catalogue; this picks a file from a library that can run to hundreds of captures with long paths.     The 2 × 2 mapping pays off twice. Approve and cancel are drawn in the screen corners matching their physical switches — FS1 top-left, FS4 bottom-right — so the prompts are diagonal opposites and cannot be hit by accident. Touch is deliberately dead on this screen. The whole point of the flow in README.md is that a network-initiated reset requires someone physically present; leaving a tappable button on screen would quietly defeat that. The screen says so rather than leaving a dead control unexplained.

    The code is the largest thing on screen because it is the only thing being asked of you. The mDNS hostname sits directly beneath it so both can be read in one glance from a laptop, and the HTTP warning is stated plainly rather than buried — README.md is explicit that direct LAN access is unencrypted and the UI must say so. "Skip for now" exists because the pedal makes sound without an account, and a first-run screen that blocks playing would be wrong for this product.

    Two different failures, two different places. The clip annunciator is transient telemetry refreshing at 1 Hz, so it sits in the top rail alongside the other status legends and names the first stage that crossed full scale — the diagnosis README.md already produces for --clip-debug. The latched overload bypass is a persistent condition that changes what you are hearing, so it takes the bottom rail with an explicit clear action. Neither uses `lamp`: in Slate that colour is red and reserved for the live preset, so both faults use the dusty `verb` lamp and a fault border instead.

    Discrete steps, no spinner. A rotating or pulsing indicator is animation for its own sake and, on a 16-bit panel, any soft-edged one bands. Seven flat blocks fill as the real startup stages complete, so the progress means something. The build and device ID sit at the bottom because a boot screen is the one place that information costs nothing and is occasionally exactly what you need.
