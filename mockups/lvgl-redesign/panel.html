Direction D — Panel

The nomenclature plate of an instrument — not a rendered panel with fake knobs, but the engraved graphic system itself: bracketed function groups, printed travel scales with numerals, patch-point circles, section legends. Quiet by construction. Colour appears only where it groups something, and one warm amber lamp means live across the whole system.

The screen is a map of the enclosure. enclosure.openscad puts the four footswitches at the four corners of the top panel with the display between them, so the patches occupy the same quadrants and each tile carries its switch in its own outer corner. You stop translating "patch 3" into "which pedal is that" — the tile is where the foot goes. Beyond that, restraint does the work: three modules are near-identical bone-on-graphite and the running one differs by a lit lamp, a full-chroma header and a coloured numeral.

Confirmed layout, and cheaper than it looks. FS1 top-left, FS2 bottom-left, FS3 top-right, FS4 bottom-right — now recorded in docs/hardware-assembly.md. The build already draws this screen as a 2 × 2 grid; it just assigns cells in reading order (LvglUiPreset.cpp:196), so slots land 1, 2 / 3, 4. Column-major gives 1, 3 / 2, 4 and the two expressions simply swap. Everything above the transpose is restyling. It also puts factory-reset approve and cancel (FS1 and FS4) on opposite corners, which is worth keeping.

What this costs in LVGL

  • Almost free. Flat plates, 1px rules, small solid rects. No gradients, no images required for the core system — this is close to the cheapest thing LVGL can draw.
  • Engraved tick scales are the one repetitive cost: 9–15 thin rects per control, six controls per page. Build them once as a reusable widget and cache it; the existing parameter-view caching by control signature already handles exactly this case.
  • Fonts: Saira Condensed at four sizes plus Saira Light at three. The 184 px tuner glyph is a 12-character subset. Modest — roughly half of Direction C's font bill.
  • Lamps are 11 px solid squares. If you want a round lamp, LVGL's radius on a small object is cheap; if you want a glow, don't — that is a ramp and it will band.
  • Genuine stretch: the bypass patch cord routed over a module needs an lv_line drawn above the module layer with correct z-order during drag. Small, but it touches the drag code.
