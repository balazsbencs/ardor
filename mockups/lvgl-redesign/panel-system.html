Panel — the remaining pieces

Module drawer, annunciator toasts, the unsaved-changes dialog, settings with the palette switcher, and the five-band EQ editor. Slate is the default palette. Ink and Sodium are runtime themes — the switcher below swaps one class on every screen, which is precisely the mechanism the device would use.

The drawer is a rack, not a modal. It takes the right 480 px and dims the chain behind it rather than covering it, so the insertion point you chose stays visible the whole time — the dashed slot on the rail shows exactly where the module lands. Family colour is carried by the same 26×3 engraved tick the preset tiles use, so nothing new enters the vocabulary. Filters wrap to two rows because seven of them will not fit across 480 px at a touch-legible size, and the count line is there because "38 available" is genuinely useful when a filter is on.

Built as annunciator strips, not floating pills. Each is a plate with a lamp cell on the left, exactly like the caution annunciators on the instruments this world comes from — so a toast is recognisably part of the panel rather than a web notification dropped on top of it. Five are stacked here to show the range; in use you would see one, occasionally two.

Fault is never carried by hue alone. In Slate the LIVE colour is red, so an error cannot also be red without collapsing the system's one reserved meaning. Faults therefore get a dusty lamp, a distinct border and a diagonal hatch across the body — three signals, none of them requiring you to distinguish two reds at foot level. That rule holds in all three palettes.

Palette is a theme, not a colour picker. Each option is previewed as the actual plate, lettering, LIVE lamp and the six family colours together — because those relationships are the thing being chosen, and a swatch grid of individual colours would let a player build a combination that breaks the system. This replaces the existing global accent picker rather than sitting beside it.

Three parameters, two axes — so Q gets its own affordance. Dragging a handle sets frequency and gain, as you would expect. The selected band additionally grows two shoulder grips sitting on the curve at its −3 dB points, joined by a dashed bandwidth span. Dragging either grip inward narrows the band and outward widens it. That is not a convention borrowed from a plugin — the grips are literally on the bandwidth edges they control, so the gesture and the physics are the same thing.

And a path that never depends on a gesture. The selected band opens an editor strip with all three values as engraved travel scales, so Freq, Gain and Q are each directly settable with a fingertip — no discovery required, and it works with a boot on. The encoder drives the highlighted control, which is the real answer for Q: the pedal already has a rotary encoder doing nothing but master volume, and Q is exactly the parameter that wants a fine continuous control rather than a drag across 200 px.

A curve is safe on this panel; a fill is not. The response is a 2.5 px stroke on a flat recessed plate — no shaded area beneath it, because a soft fill is a ramp and would band exactly like the old gradients.
